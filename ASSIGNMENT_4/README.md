# Assignment 4 — Hypothesis Testing

## Overview
Covers t-tests, z-tests, chi-square tests, ANOVA, and p-value interpretation for real-world datasets.

## Parts
| Part | Task | Description |
|------|------|-------------|
| **A** | One-sample & Two-sample t-tests | Test hypotheses about population means |
| **B** | Z-tests & Proportions | Large-sample hypothesis testing for proportions |
| **C** | Chi-Square Tests | Test independence between categorical variables |
| **D** | ANOVA | Compare means across 3+ groups |

## Files
- `notebooks/` — Jupyter notebook with full analysis
- `outputs/` — Generated plots and test result tables
- `scripts/` — Standalone Python scripts

## How to Run
```bash
jupyter notebook ASSIGNMENT_4/notebooks/hypothesis_testing.ipynb
```
