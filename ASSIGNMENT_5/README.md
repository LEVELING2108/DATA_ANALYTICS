# Assignment 5 — Regression & Model Building

## Overview
Covers simple & multiple linear regression, model evaluation (R², RMSE, MAE), residual analysis, and assumptions validation.

## Parts
| Part | Task | Description |
|------|------|-------------|
| **A** | Simple Linear Regression | Build & interpret a single-predictor model |
| **B** | Multiple Linear Regression | Multi-predictor model with feature selection |
| **C** | Model Diagnostics | Residual plots, homoscedasticity, normality checks |
| **D** | Model Comparison | Compare models using R², Adjusted R², AIC, BIC |

## Files
- `notebooks/` — Jupyter notebook with full analysis
- `outputs/` — Generated plots and model comparison tables
- `scripts/` — Standalone Python scripts

## How to Run
```bash
jupyter notebook ASSIGNMENT_5/notebooks/regression_model_building.ipynb
```
